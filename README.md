## 架构特性

| 特性 | 说明 |
|------|------|
| DeepNorm | 深层网络稳定训练, α=(2L)^0.25 = 1.6818 |
| GQA | 分组查询注意力, KV头压缩至1/4 (4:1) |
| MoE | 4专家Top-K=2路由 + SwiGLU激活 |
| RoPE | 旋转位置编码, θ=10000 |
| ALiBi | 线性偏置注意力, 每头独立斜率, 支持长序列外推 |
| Sliding Window | 滑动窗口注意力 (window=32), 高效长上下文 |
| 链式法则反向传播 | 完整的梯度计算: CE→Head→LN→Attention→MoE→Embedding |
| 梯度裁剪 | 全局范数裁剪 max_norm=1.0 |

## 反向传播修复详情

### 修复的问题

1. **假反向传播** → 真实链式法则反向传播
2. **ALiBi单一斜率** → 每头独立几何递减斜率
3. **SwiGLU重复计算** → gate_pre只计算一次
4. **Embedding未更新** → scatter-add梯度更新
5. **LayerNorm固定常数** → 真实梯度计算
6. **无梯度裁剪** → 全局范数裁剪 max_norm=1.0
7. **无前向缓存** → 完整中间值缓存

### 反向传播流程

```
Loss(CE) → dLogits
  → dHead, dHeadBias, dXFinal
    → FinalLayerNorm反向
      → Transformer Blocks (逆序)
        → 残差2反向 → FFN/MoE反向 → LN2反向
        → 残差1反向 → Attention反向 → LN1反向
      → Embedding反向 (scatter-add)
        → 梯度裁剪 (global norm)
          → SGD参数更新
```
